## 🚨 RECOVERY MODES

### If You Miss 1 Day

**System Response:** Nothing (normal variation)

**Your Action:**
- Don't panic
- Complete today's plan
- Log health

### If You Miss 2-3 Days

**System Response:** Recovery Mode Activated

**Your Action:**
- Complete 1 missed topic only
- Maintain health routine
- NO new topics today
- System will redistribute workload

### If You Miss 4-6 Days

**System Response:** Emergency Reset

**Your Action:**
- Pause all new topics for 2 days
- Only P1 topics (%, Ratio, Average, Series, Analogy)
- Reduce GK to flashcards (15 min)
- Maintain 5AM wake + walk
- System creates catch-up plan

### If You Miss 7+ Days

**System Response:** Rebuild Mode

**Your Action:**
- Drop to minimum viable plan
- Keep only CGL + 1 other exam
- P1 topics only for 1 week
- Take 1 full rest day this week
- System will help you restart gradually

## 💡 PRO TIPS

### Maximizing Productivity

1. **Pomodoro Technique**
   - 25 min study + 5 min break
   - After 4 Pomodoros → 30 min break
   - Use phone timer or app

2. **Error Logging**
   - Log EVERY wrong answer
   - Categorize: Concept/Formula/Calculation/Silly
   - Review errors weekly

3. **Revision System**
   - Trust the 1/3/7/15/30 intervals
   - Don't skip revisions
   - Flashcards for GK/English

4. **Mock Analysis**
   - 2 hours analysis > 1 hour mock
   - Identify weak areas
   - Create improvement plan

### Health Optimization

1. **Sleep**
   - 7.5 hours non-negotiable
   - No screens 1 hour before bed
   - Same sleep/wake time daily

2. **Water**
   - 1L marked bottle × 3 = 3L
   - Sip throughout day
   - Not all at once!

3. **Walking**
   - Brisk pace (can talk but not sing)
   - GK podcast during walk
   - Hit 10K steps total

4. **Strength**
   - Start with wall push-ups
   - Progress to floor push-ups
   - Target: 20 push-ups by Month 3

### Mental Game

1. **No Guilt**
   - Missed a day? System adapts
   - Behind schedule? Recovery mode
   - Perfection not required

2. **Consistency > Intensity**
   - 6h daily > 12h some days
   - Small habits compound
   - Trust the process

3. **Focus on Process**
   - Don't obsess over cutoff
   - Focus on daily execution
   - Results will follow
